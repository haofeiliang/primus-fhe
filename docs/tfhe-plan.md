# TFHE 实施步骤

设计依据见 [总览](tfhe.md)，算法细节见 [稀疏 PBS](tfhe-sparse-pbs.md) 与 [分解式 MVB](tfhe-mvb.md)。本文定义任务和完成条件；当前状态以 [HANDOFF](../HANDOFF.md) 为准。步骤是可独立验证的工作单元，不意味着自动暂存或提交。

## 恢复与推进规则

1. 先核对 Git 的暂存/未暂存状态，读取 HANDOFF 中的已完成编号、当前步骤和下一步。
2. 读取本步骤及其引用的契约，按源码入口核对当前实现；历史行号和测试结果不作为当前事实。
3. 上一步未完成时，先处理其剩余工作；不要因上下文压缩重新创建计划或重复重构。
4. 每步结束，公开契约写回 rustdoc/README，局部理由写回源码，跨层决定更新设计文档。HANDOFF 只替换进度、有效未决项和下一步。
5. 新的数学问题、参数条件或设计变更记录在对应待决项；不静默改变输入域、秘密分布、编码或比较基线。
6. 未获源码实施指令时只完善计划。研究条件未收敛时，继续不依赖它的任务，不用猜测的默认参数掩盖问题。

## 阶段与依赖

| 阶段 | 步骤 | 阶段完成的含义 |
| --- | --- | --- |
| P1 公共 LUT | P1.1 → P1.M → P1.2 → P1.3 → P1.R → P1.4 | 精确几何、直接编译、分离数量/步长，统一量化边界并迁移现有调用方 |
| P2 基础功能 | P2.1 → P2.2 / P2.3 | 输出编码可选、有界双输入、经验证的奇数全域模式 |
| P3 稀疏 GLWE NTT | P3.1 → P3.2 → P3.3 → P3.4 → P3.5 | 固定重量二元完整 PBS、参数契约、可复现的成本比较 |
| P4 MVB | P4.0 → P4.1 → P4.2 → P4.3 | 一种具体 MVB 的实现与适用范围，不包含所有大 LUT 研究路线 |

默认按 P1、P2、P3、P4 推进。P3 与 P4 在 P1 完成后，可先做各自的设计收敛；稀疏 BR 不依赖双输入或奇数全域。P4 若选择依赖新输出编码/域的方案，再显式依赖相应 P2 步骤。

## P1.1 精确旋转与布局契约

**范围：** 共享 LUT、modulus switch、现有测试及四后端消费方式。

**工作：**

- 定义 `t, D, N, k, s, q_in, q_acc`，明确现有符号和负循环方向；区分编译几何与执行量化。
- 确认哪些数据须附在 LUT 中，哪些只供构造期扫描；复用已有编码类型，不预先增加持久中心数组。
- 用小环、简单独立的负循环旋转和宽整数舍入 oracle 验证提取值；不能只比较两个调用同一 helper 的实现。
- 保存可复现的原实现基线，固定参数、工具链和 feature。新编译 benchmark 与旧实现比较时须测同一负载；同时保留现有在线 PBS 基线。

**完成条件：** 现有有效域、回绕、规范 residue、Native/显式模数边界有明确契约和聚焦 oracle。这里只建立当前行为基础，不开启奇数全域或稀疏内核。

## P1.M 模数侧缩放与量化（P1.2 前置）

**依赖：** P1.1。**范围：** reduce、modulus/derive、encoding、LWE/GLWE/NTRU 参数与 TFHE 调用方。

- 增加固定模数对准备与执行能力；`source.prepare_switch_to(target)` 返回只需输入系数的转换对象，统一规范剩余类、舍入和末端回绕。`RingContext` 聚合准备能力，执行对象独立保存比例、位移和数值界；codec 可单独约束准备能力与模加法。
- Rounded/Scaled codec 保留 `M`，构造时准备所需转换；保持逐消息舍入、固定舍入尺度、Centered/Unsigned 的区别。商余数和窄/宽策略归位到准备实现；批量分派保持在循环外。
- codec、基础加解密及通用 TFHE client 的数值输入输出使用系数类型 `T`，批量消息使用 `[T]`，应用按需转换类型；Boolean 等语义接口保留各自类型。参数构造复用 codec 校验；模数有效性由模切准备验证，codec 保留 `q > t` 和 Scaled 恢复条件。
- TFHE 编译与在线量化保留输入模数类型；输入与 accumulator 模数独立。ManyLUT 仍先量化到 `2N/s` 再乘 `s`。
- Native/PowOf2 使用相应整数特化，显式模数共享精确内核；Barrett 倒数求商需另有正确性与性能依据，不作为本步前提。
- 迁移实际调用方、派生 Barrett、测试、基准与双语文档；分解、采样、NTT/Fourier 表示不因接口整齐而扩展。

**完成条件：** 现有编码及 P1.1 独立 oracle 通过；覆盖二次幂、显式模数及舍入/回绕边界；完成受影响包默认/SIMD 验证和 codec、完整 PBS 的同配置比较。记录性能限制，不将移除类型擦除等同于加速。下一步仍为 P1.2 的编译核心优化。

## P1.2 单次几何扫描与直接填充

**依赖：** P1.M。**范围：** 共享编译核心及编译 benchmark。

先在 P1.M 完成的源码上采集构造对照，以区分模切接口调整和本步几何优化的影响；P1.1 数据继续作为初始参照。

- 几何计算与输出求值/布局填充分离；所有列共享中心和边界，Many 直接写最终多项式。
- 单输出复用相同几何；必要的输出组 scratch 仅分配一次，不增加大型重复几何存储。
- 收尾时由编译函数直接推进中心与系数区间，普通区间和负循环尾部各用一个私有填充函数；以重整前的 P1.2 实现复测。涉及有效数量/步长的校验和 family 包装留给 P1.3。
- 暂时保持既有公共输入域和二次幂输出数量约束，降低与 API 迁移的耦合；保留回调报错和原始输出 residue 检查。
- uniform/power-of-two 特化只在等价且有实测收益时加入，不是本步前提。

**完成条件：** 独立 oracle 通过；没有逐列多项式分配；报告构造时间/分配变化，不把构造收益写成在线 PBS 加速。

## P1.3 布局 API 与调用方完整迁移

**依赖：** P1.2。**范围：** 七个 TFHE crate 及 workspace 实际调用方。

- 分开有效输出数 `k` 与交错步长 `s`；支持 `k=3, s=4`，提取 `0..k`，由编译器补齐其余槽。
- 收敛普通/交错 LUT 命名及必要元数据，集中兼容性检查。
- 将 `compile_encoded_lookup_table` / `compile_encoded_many_lookup_table` 迁为对应 LUT 类型的 `try_new` 关联构造器；保留已编码输出与 `Result` 契约，迁移调用方并删除自由函数。
- 同步两族 LUT 包装、四个 context/evaluator/BR、三个 CBS；CBS 以有效数量构造 LUT，以实际布局绑定 key、量化和提取。
- 保持 Boolean raw 尺度、普通/CBS 输出的独立语义；更新多输出 trait 中只适用于交错算法的执行承诺。
- 若移除 family wrapper，明确谁接收其检查/编码职责；全 workspace 迁移后删除旧 API，不留无用途兼容层。

**完成条件：** 四后端支持数量与步长不同的情况；两种 GLWE 顺序、NTRU 固定链及三路 CBS 的布局/basis 绑定和投影保持正确。任意输出数在本步完成，P2 不重复安排。

## P1.R 取整契约与旋转域边界

**依赖：** P1.3。设计理由、居中量化实验及接入决定见 [取整策略取舍](tfhe.md#p1r-取整策略取舍)。

本步整理当前量化能力，并验证均匀二元秘密的 Centered / shifted 可行性，不预先实现全部舍入模式。

- 统一 PBS 参数、LUT 和 `RotationQuantizer` 的边界：`2N` 本身须能由输入系数类型 `T` 表示，普通目标为 `2N`，交错目标为 `2N/s`。删除 quantizer 为满字宽目标准备 `NativeModulus` 的分支；保留 Native 输入，以及通用模切供编码使用的 Native 目标。
- 校验放在拥有契约的公开构造边界，私有执行路径复用已建立的不变量。检查两族参数、四路 BSK/BR 和 raw helper 的边界是否一致；不为共享一行判断新增公共类型。
- 固化现有语义：规范非负 residue 的模切/解码 nearest ties-up；Rounded 的有符号 lift 编码 nearest ties-away-from-zero；Scaled 保持固定尺度。只补充缺失的契约或独立边界测试，不重复现有 oracle。
- 更新原先接受 `2N=2^T::BITS` 的 helper 测试和文档，覆盖可表示的最大旋转域、拒绝边界以及交错步长。保留 Native/显式输入及标量/批量一致性覆盖。
- 用临时整数原型分别验证居中 body 补偿和 LUT shift：独立 oracle、小域 LUT 边界、普通/交错量化误差，以及 Native/Fourier、Barrett/NTT 完整 PBS 的额外成本。先限定均匀二元秘密；固定重量稀疏分布留待对应阶段。根据结果决定正式接入范围，不以实验通过替代失败概率推导。
- Floor、Ceil、其他 tie 规则和随机舍入等待具体消费者；带加密零样本的漂移抑制单独规划。保存实验方法、结果和未决条件，清理临时原型，不将未经收敛的策略加入默认调用流程。
- 后续批准的内核优化：保持公共 trait 和 `ModulusSwitch<T>`，改进二次幂扩张策略并加入紧凑范围的单字/双字倒数求商。核对标量、批量 oracle 和消费者性能；PBS 批量融合原型未显示稳定收益，已删除。见[固定模数对内核优化](tfhe.md#固定模数对内核优化)。

**完成条件：** 当前有效 PBS 参数的舍入结果和推荐调用流程不变；超出统一旋转域的输入在构造边界明确拒绝；居中/shifted 的验证结果和接入决定有证据。不新增无人消费的策略 enum/trait 或 LUT 字段。针对受影响包验证，最终性能汇总仍由 P1.4 完成。

## P2.1 输入与输出编码分离

**依赖：** P1。

- 普通编译允许显式选择输出编码，保留 raw 已编码入口。
- 明确输出 codec、累加器模数及最终输出表示的关系，避免输入尺度侵入 Boolean/CBS。
- 用输入与输出模数/尺度不同的实际案例验证编译、PBS 和解码，覆盖受影响路径。

**完成条件：** 公开推荐工作流支持该案例，raw 及既有路径不退化；兼容性检查不混淆输入和输出角色。接口决定与验证范围见 [P2.1](tfhe.md#p21-输入与输出编码分离)。

## P2.2 有界双输入入口

**依赖：** P2.1。

- 实现最小的 `x + B*y` 打包/编译工作流，明确两输入维数、秘密、模数、尺度与范围。
- 按实际调用方决定入口所属层，不引入完整整数/message-carry 类型系统。
- 说明线性组合误差和防止消息回绕的条件；小域独立穷举索引，并增加固定 seed 的端到端案例。

**完成条件：** 打包与真实编码一致、容量条件明确；不能将其描述为任意精度双输入 PBS。接口和舍入误差决定见 [P2.2](tfhe.md#p22-有界双输入-pbs)。

## P2.3 奇数明文模数全域

**依赖：** P1、P2.1（显式输出 codec）；不依赖 P2.2。

- 推导带符号中心折叠，用真实 codec/模切验证排序、符号、碰撞和回绕。
- 明确独立编译模式和参数条件，不推广为任意偶数模数全域开关。
- 小奇数模数遍历全域与区间边界，验证中心不足的拒绝行为；区分几何余量与完整 PBS 失败概率。

**完成条件：** 全域语义和适用条件有独立依据及端到端验证；前半区接口行为保持明确。接口、符号推导及验证边界见 [P2.3 决定](tfhe.md#p23-奇数明文模数全域)。

## P3.1 稀疏方案与参数收敛

**依赖：** P1 旋转契约；阅读 [专项文档](tfhe-sparse-pbs.md)。

- 首版固定 GLWE NTT、固定重量二元实际 BR 秘密。
- 确认 PBC 映射、复制数、桶数、私有分配、失败重试分布和噪声预算；结构化 one-hot 不能冒充一般固定重量分布。
- 写清桶聚合与最终旋转不变量，复核论文校勘。
- 选择安全依据明确标注的实验和经典对照参数；未经论证的设置只能标为实验候选。

**完成条件：** 密钥布局、参数依据、失败行为和评价标准足以指导实现。研究未决项不能用“测试能解密”关闭。

**已完成的决定：** 见 [P3 实现契约](tfhe-sparse-pbs.md)。首版实验参数组固定 `c=3,b=2h`、完整匹配、同一秘密最多尝试 8 个独立映射，使用系数域 GGSW 桶存储。已给出失败上界、重试后的联合分布、旋转/噪声递推、两组实验参数与等价经典对照。生产安全与完整失败率仍未认证，不作为本阶段已经解决的结论。

## P3.2 PBC 与稀疏 BSK

**依赖：** P3.1。

- 实现每个索引的不同桶副本与 keygen 私有完整匹配：每个支持位置选择一次、每桶至多一个；所有桶都有独立加密 dummy，未选中支持位置时 dummy 明文为 1。
- 具体 BSK 表达桶布局、选择密文及必要参数；公开数据不保存支持集或私有分配。
- 复用已有固定重量分布和 GGSW 原语，检查实际二元系数/重量；固定秘密重采映射，8 次耗尽返回错误。
- 小实例验证覆盖、去重、空桶、碰撞重试；不从真实密钥导出辅助明文位置。

**完成条件：** 秘密分布和结构符合 P3.1；evaluator 可由持有的 key 数据建立，不依赖 keygen 的明文秘密或临时缓存。

**已完成的实现：** NTT 后端的 `KeyGenerator::try_generate_sparse_bootstrapping_key` 生成 `SparseGlweBootstrappingKey`，保存公开桶映射和系数域选择/dummy GGSW；支持集、匹配和明文位只存在于会擦除的 keygen 临时缓冲区。已验证完整匹配、最多八次重试、实际重量校验及加密语义，见[实现入口](tfhe-sparse-pbs.md#p32-实现入口)。

## P3.3 参考盲旋转

**依赖：** P3.2。

- 先实现清楚的系数旋转/聚合，再使用现有 NTT/external product；复用 scratch，不先加入巨大预计算。
- 明确符号、量化和累加器初始化，预计算重复使用的输入旋转量。
- 小环独立检查全部旋转；与已知秘密的直接总指数旋转比较最终相位。
- 有噪声时比较解码/误差界，不要求不同算法密文字节相同。

**完成条件：** 满足旋转不变量，外积次数等于桶数；经典路径仍可作为功能和成本对照。

**已完成的实现：** `SparseGlweBootstrappingKey::ntt_blind_rotate_lookup_table_to` 与 `SparseGlweBlindRotationContext` 提供步长 1 的参考盲旋转；逐输入量化、逐桶聚合、NTT 和一次外积，在线零分配。小环全指数 oracle、同秘密经典对照与真实加密输入验证见 [P3.3 实现与验证](tfhe-sparse-pbs.md#p33-参考盲旋转实现与验证)。后续聚合、变换及工作区测量见 P3.4。

## P3.4 聚合、表示与工作区优化

**依赖：** P3.3。

- 先测桶聚合、变换、外积和内存成本，再选择布局。
- 评估连续旋转切片、按桶变换、预备旋转量；全旋转 NTT 预计算不作为默认。
- 固定条件测在线分配、BSK 常驻量、工作区峰值和完整耗时。
- 保留能回答稳定问题的 benchmark，清除仅用于选型的临时实验。

**完成条件：** 保留的优化有可复现依据，参考 oracle 不随优化共用同一易错实现。

**已完成的实现：** 测量两组参数的聚合、NTT、外积、原始 BR 及实际分配；保留 dummy 初始化、按整多项式分块聚合和原地 NTT，工作区减少一份 GGSW。连续旋转切片及其他无稳定收益的原型未保留，仅新增四项原始 BR 对照基准。默认/SIMD 性能和内存边界见 [P3.4 测量](tfhe-sparse-pbs.md#p34-聚合表示与工作区测量)。完整 PBS 接入见 P3.5。

## P3.5 完整 PBS 与组合验收

**依赖：** P3.4。

- 接入普通/交错 LUT；验证 GLWE 两种顺序中稀疏条件作用于正确的秘密。
- CBS 复用须同时满足布局、秘密和噪声条件，单凭同一旋转公式不能宣布支持。
- 比较完整 PBS、keygen、BSK 大小及工作区，公开参数、CPU、工具链、feature 和测量边界。
- 标明已实现组合；Fourier、三元、NTRU 移植另立方案，不作为首版条件。

**已完成的实现：** `ServerKey` 保存经典或稀疏 BSK，`try_generate_sparse_server_key` 复用原 KSK，

## P4.1 MVB 算法与编码选型

**依赖：** P4.0；具体输出/域需求可引入相应 P2 依赖。

- 比较交错 ManyLUT、因子分解与 BR 展开，选择有实际应用场景的首版算法和后端。
- 对所选域证明分解/恢复，明确 `1/2`、native/显式模数、舍入、系数范数及输出噪声。
- 按算法决定共享编译产物与后端预处理的边界。

**完成条件：** 局部可检查的代数依据、参数和成本模型；只承诺实际能支持的模数/后端。

**完成记录：** 选择 GLWE NTT 的固定尺度差分分解，输入为现有前半区/短前缀 Rounded
几何，统一 Scaled 输出；奇数 `q` 下 `V=(Delta*inv2)*sum(X^j)`、`W_i=(1-X)p_i`。
保持步长 1，复用经典/稀疏 BR 和两种 order；BK 首版逐输出乘后 KS，KB 保持前置 KS。
完整代数、Native 限制、噪声/范数、预处理/工作区、成本与整数 oracle 记录见
[P4.1 方案](tfhe-mvb.md)。本步未修改 Rust 或进行加密/性能验收，下一步 P4.2。

## P4.2 首个 MVB 实现

**依赖：** P4.1。

- 按 [MVB 方案](tfhe-mvb.md) 实现共享 `FactorizedLookupTable`：真实输入几何、统一
  Scaled 输出、共同原始多项式与整数差分；保持 output_count 为 usize，不补齐槽。
- 补 Scaled codec 的模数访问器；后端消费共享产物并原地预处理因子，绑定生成它的
  context，防止相同 q/N 的不同 NTT 表混用。context 提供简洁的便捷编译入口。
- GLWE NTT 独立 FactorizedEvaluator 复用 P4.0 阶段，仅增加一个共享 NTT GLWE
  scratch。BK 逐输出乘后 KS，KB 前置 KS；经典/稀疏均保持现有外部秘密域及零分配。
- 按方案末尾的最小验证矩阵保护代数、真实几何、编码、context/输出拒绝边界与两种
  order。独立 PBS/交错对照必须使用相同 Scaled 输出中心；不改交错 trait。

**完成条件：** 选定范围内的完整多输出工作流正确，默认/SIMD 验证及在线零分配通过；
公开契约与双语文档完整。首版不扩展 odd full-domain、其他后端、CBS 或秘密分布。

**完成记录：** 已实现共享 `FactorizedLookupTable`、绑定 context 的
`NttFactorizedLookupTable` 和独立 `FactorizedEvaluator`。经典/稀疏、两种 order、
Scaled 输出与既有 PBS 对照及在线零分配通过；新增两个共享测试和一个集成测试。
实际接口、验证参数与边界见 [MVB 实现契约](tfhe-mvb.md#5-编译产物预处理与工作区)。
