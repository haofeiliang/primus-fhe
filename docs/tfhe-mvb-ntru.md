# NTRU NTT MVB：B3.2 误差与成本

本次测量基于 `c489b2b` 的连续因子存储和 NTRU MVB 完整链，日期为 2026-09-18。
共享代数、编码与布局见 [MVB 设计](tfhe-mvb.md)；本页只保存 NTRU 的参数、分阶段诊断和成本。
生产 evaluator 与密钥接口未改变；新增[常驻基准](../crates/primus_tfhe_ntru_ntt/benches/mvb.rs)
和[应用示例](../crates/primus_tfhe_ntru_ntt/examples/ntru_ntt_mvb_thresholds.rs)。

## 1. 等价负载与参数

一次调用从一个加密分数生成 `k` 个数值阈值标志：
`f_i(m) = [m >= floor((i+1)D/(k+1))]`，`i=0..k`。
两组为 `D/k=8/3、64/17`，输入为 Rounded `t_in=2D`，输出为 unsigned Scaled `t_out=2`。
重复 PBS 与交错 ManyLUT 用 raw LUT 编译器写入**相同 Scaled 中心**，不以 Rounded 输出替代。

| 参数 | 取值 |
| --- | --- |
| 字宽、密文模数、环长度 | `u32`，`q=132120577`，`N=1024` |
| 外部 LWE | `n=728`，fixed-weight binary，`h=32`，其余 NTRU 系数补零 |
| Accumulator 秘密 | `SparseTernary` |
| 输入 LWE 噪声标准差 | `3.2*q/16384 ≈ 25804.8` |
| 初始化/BR、KS 加密噪声标准差 | 均为 `0.7` |
| BR、KS 分解 | 均为 `log_basis=7`、`level_count=None`，实际 3 层、舍弃低 6 位 |
| 密钥及输入 RNG | `StdRng`，每组 seed=`0xB3020000+D`，先生成配套密钥再加密输入 |

这是逐坐标经典 NGSW BR，**不是桶聚合稀疏 BR**。固定重量减少系数独立量化的累计误差，
有利于窄 LUT 区间；NTRU 还会按可逆性拒绝采样，实际秘密分布因此带条件。
这些是功能/成本参数，不提供生产安全或完整失败率结论，也不与 GLWE 作等安全比较。

## 2. 完整调用时间

[计时 CSV](benchmarks/tfhe-b3.2.csv) 保存均值和 95% bootstrap 置信区间。
环境为 Ryzen 9 9955HX3D、x86_64 Linux、CPU 2；默认 rustc 1.98.0
（88d9e12ae），SIMD nightly 1.100.0（bff8e12ff）。使用仓库 `target-cpu=native`，
Criterion 0.8.2，20 样本、预热 1 秒、测量 3 秒、Flat sampling；串行计时，不并行编译。
频率未锁定，governor 为 powersave、boost/SMT 开启；置信区间不包含跨运行环境变化。

输入池为 `0、D/4-1、D/2、D-1`，每次迭代轮换一个输入，计算全部输出。
密钥、程序、输入/输出、evaluator 均提前准备并复用；计时包含初始化、BR、公开乘法、KS、提取。
每条路径计时前验证输入池的全部输出；只保留五项在线基准，不重复测共享 LUT 编译器。

下表单位为 ms，每格依次是 **默认 / SIMD**：

| D / k | 重复 PBS | 交错 ManyLUT | MVB |
| --- | ---: | ---: | ---: |
| 8 / 3 | 5.703 / 5.706 | 1.894 / 1.894 | 1.855 / 1.886 |
| 64 / 17 | 32.433 / 32.231 | 容量不足 | 1.966 / 1.943 |

本负载 MVB 相对重复 PBS 约快 **3.0–3.1 倍 / 16.5–16.6 倍**。三输出与交错路径接近，
本次差异约 −2.0% / −0.5%，不据此认定 MVB 总比交错快。17 输出的交错布局需要
32 槽，`N/32=32<D=64`，构造明确拒绝，不能列出同等功能的虚拟耗时。
两套工具链不同，不把默认/SIMD 的小差异单独归因于向量化。

```sh
taskset -c 2 cargo bench -p primus_tfhe_ntru_ntt --bench mvb -- \
  --sample-size 20 --warm-up-time 1 --measurement-time 3 --save-baseline b3_2_default
taskset -c 2 cargo +nightly bench -p primus_tfhe_ntru_ntt --features simd --bench mvb -- \
  --sample-size 20 --warm-up-time 1 --measurement-time 3 --save-baseline b3_2_simd
```

## 3. 密钥、程序与工作区

[资源 CSV](benchmarks/tfhe-b3.2-resources.csv) 使用线程局部分配计数，报告构造结束时
仍存活的请求字节数；含 Vec capacity，排除 allocator 元数据、栈、共享 context 和诊断副本，
不是 RSS。密钥生成器 scratch 在测量窗口外，构造中的临时分配计入次数和累计请求后释放。
默认/SIMD 的所有资源计数相同，CSV 只保存一份。

| 对象 | 两组共同取值 |
| --- | ---: |
| 客户端两个秘密 | 8,192 B |
| 完整 server key，无 CBS | 8,970,312 B |
| 普通 evaluator | 21,504 B |
| MVB evaluator | 25,600 B |

MVB 使用原 server key，额外 scratch 恰为 `N*sizeof(u32)=4096 B`，与输出数无关。
服务端密钥含 728 份控制、1 份初始化 NLev、1 份 KS NLev，以及 basis 的动态数据。

| D / k | 重复 PBS 程序总计 | 交错程序 | 已准备 MVB 程序 | 输出密文及其 Vec |
| --- | ---: | ---: | ---: | ---: |
| 8 / 3 | 12,456 B | 4,096 B | 16,384 B | 8,820 B |
| 64 / 17 | 70,584 B | — | 73,728 B | 49,980 B |

MVB 程序两次分配：共同 `V` 一块、全部 `W_i` 一块；NTT 准备原地完成。
所有被测完整在线路径从首次调用起零分配。输出数越多，程序和输出仍线性增长，
共享 BR 不代表所有持久数据都与输出数无关。

## 4. 分阶段误差与相关性

### 诊断方法

使用与基准相同的参数和密钥 seed，但输入按 `m=j%D` 逐个重新加密：D=8 测 64 个输入，
D=64 测 128 个输入。三条算法在各组内共享密钥及输入。相位由实际秘密解密，
误差采用模 q 的居中代表；输出误差是相对预期 Scaled 中心的差，不是解码后的消息差。

记 `b̄=R(b)`，`ā_i=R(a_i)`，`A=Σ ā_i*s_i mod 2N`。逐阶段诊断如下：

1. 单独执行正式初始化外积，得到 `phase(c_init)=X^(-b̄)V+e_init`。
2. 调用正式 BR，令其相位减去 `X^(A-b̄)V` 得到 `e_shared`；再减去
   `X^A e_init`，定义本次 BR 新增误差 `e_BR`，包含分解近似和控制加密误差。
3. 各输出先乘 `W_i`，计算系数零的两项贡献
   `u_i=coeff_0(W_i*X^A e_init)`、`v_i=coeff_0(W_i*e_BR)`。
   独立的有符号负循环系数乘法核对 `u_i+v_i` 与真实乘后相位误差一致（模 q）。
4. 对实际乘后密文执行正式 KS，令输出 LWE 相位减去 KS 前乘积的相位得到 `k_i`；
   核对最终误差 `e_i=u_i+v_i+k_i mod q`。完整输出逐字与正式 MVB 调用比较。

诊断还检查实际量化位置给出的理想输出等于 `f_i(m)`，以及
`|pre_KS_error_i| <= ||W_i||_1 * ||e_shared||_∞`。初始化与 BR 的统计覆盖全部 N 个系数，
乘后/KS/最终统计覆盖每个输出的提取系数，不能直接当成同一组随机变量相加 RMS。
临时内部诊断已删除，没有扩大公开访问器或增加普通 CI 的统计测试；复测按上述阶段、
seed 和输入顺序重建观测，完整调用的计时由常驻基准复现。

### 实测值

全部阈值因子均为两项，`nnz=2、L1=2、L2²=2`。`Delta=(q+1)/2=66060289` 为奇数，
共同多项式使用模逆构造；**不对带噪声密文做模除二**。
[误差 CSV](benchmarks/tfhe-b3.2-noise.csv) 保存样本数、均值、RMS、最大绝对值和相关性汇总；
默认/SIMD 汇总完全相同，只保存一份。以下为模 q 系数单位的 RMS，四舍五入到整数：

| 阶段 | D=8 / k=3 | D=64 / k=17 |
| --- | ---: | ---: |
| 初始化，全系数 | 992 | 1,626 |
| BR 新增，全系数 | 38,655 | 38,569 |
| 共享旋转结果，全系数 | 38,669 | 38,603 |
| 因子乘后的初始化贡献 | 1,474 | 2,209 |
| 因子乘后的 BR 贡献 | 52,855 | 53,077 |
| KS 前输出误差 | 53,078 | 53,150 |
| 新增 KS 误差 | 1,418 | 1,464 |
| MVB 最终输出误差 | 53,104 | 53,152 |
| 重复 PBS 最终输出误差 | 36,309 | 38,326 |
| 交错 ManyLUT 最终输出误差 | 37,160 | — |

本组最终 RMS 为重复 PBS 的约 **1.39–1.46 倍**。最终最大绝对误差分别为
160,416 / 190,181；二元 Scaled 输出的严格恢复条件是 `|y+2e|<q/2`，
共同保守对称整数余量为 33,030,143。所有诊断输出正确，有限样本不估计生产尾概率。
其他函数可能有大得多的差分范数，不能复用本组误差值。

系数独立量化还影响输入位置：普通/MVB 的最大相位指数偏移为 5 / 4，
交错三输出为 16。前两者平台偏移范围分别为 `[-64,63]` / `[-8,7]`；
交错三输出步长 4，可用范围为 `[-64,60]`，偏移只能是 4 的倍数。
这些是 2N 旋转指数单位，与表中的密文相位误差不能直接比较。

对每对输出，用全部输入样本分别去均值后计算 Pearson 相关系数：

| 输出误差 | D=8 / k=3：min–max | D=64 / k=17：min–max |
| --- | ---: | ---: |
| KS 前 | 0.357–0.610 | 0.312–0.631 |
| KS 新增 | −0.016–0.284 | −0.175–0.212 |
| 最终 | 0.349–0.605 | 0.313–0.627 |

阈值因子共享末端差分位置，共享旋转误差带来相关输出；逐输出执行 KS 也不保证
其误差独立，因为使用同一份 KSK。应用不能按独立噪声计算组合失败概率。

## 5. 应用与选择

```sh
cargo run -p primus_tfhe_ntru_ntt --release --example ntru_ntt_mvb_thresholds
```

示例把 `0..64` 的加密分数转换为 17 个阈值标志，复用程序、输入及输出缓冲区，
处理分数 12 和 45，并展示交错容量拒绝。结果是 unsigned Scaled 数值 0/1，
不是 Boolean evaluator 的内部编码；串联下一次 PBS 须核对输入编码与误差余量。

- 交错能容纳且量化余量足够时，本组在线成本相近，交错只需一份 LUT、一次 KS。
- 输出多到交错容量不足时，小范数 MVB 能共享 BR，收益明显；需接受较大的程序和相关误差。
- 大范数或不同分布/噪声配置需要重新验收，不能由本组阈值推断全部函数都适合 MVB。

B3.2 完成既有链的验收，没有改变 KS 顺序，也没有开放 NTRU ternary、桶聚合、
Fourier 或 odd full-domain MVB。下一步由 [B3.3](tfhe-backend-plan.md#b33glwe-ntt-sparse-的三个现有组合)单独验证 GLWE 的已有 sparse 组合。
